## 1. Project Overview & Scope
**UseFirst** is an AI-assisted pantry coach concept designed to help households identify, prioritize, and consume perishable food before it is forgotten. 

Rather than requiring users to scan dozens of barcodes or audit full pantries, UseFirst tests a lightweight habit: entering 3–5 perishables and receiving an immediate sorted urgency list and simple recipe ideas[cite: 2, 3, 4].

- **Project Context:** 8-Hour AI Tools Group Work Plan[cite: 1]
- **Role Ownership:** Member 3 · Product & Architecture Lead[cite: 2]
- **Prototype Status:** Standalone HTML/CSS/JavaScript demonstration[cite: 3, 5]
